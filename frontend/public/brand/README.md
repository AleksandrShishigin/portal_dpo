# Официальные материалы Московского Политеха

Источник: https://mospolytech.ru/ob-universitete/brandbook/

- `mospolytech-black.svg`: «Основной вариант / Версия для Web / На русском языке / Чёрным цветом / ЛоготипЧерныйWebRU.svg».
- `mospolytech-white.svg`: соответствующий официальный белый вариант `ЛоготипБелыйWEBRU.svg`.
- `fonts/Gilroy-*.otf`: Regular, Medium, SemiBold и Bold из официального архива `Gilroy Family.rar`. Файлы переименованы для устойчивых локальных URL; содержимое не изменено.
- `fonts/LICENSE.html`: исходное лицензионное соглашение из архива шрифта, без изменений.
- `sources.json`: ссылки, точные HEX-значения из отдельного файла «Основные цвета.pdf», размеры и SHA-256 исходников.

Логотипы подключаются через `<img>` с сохранением пропорций, без фильтров, перекрашивания, обрезки и эффектов. Чёрный вариант расположен на светлом фоне; вокруг сохранено свободное поле. SVG и OTF проверены на побайтовое совпадение с официальными архивами. Оригиналы не обрабатываются форматтером исходников.

Палитра отдельного файла по текущей ссылке брендбука отличается от дополнительных цветов старого руководства. Для UI используется отдельный файл: #000000, #FFFFFF, #EC2550, #9164C9, #2C5BBA. Нейтральные оттенки интерфейса и семантические зелёный/янтарный для статусов не объявляются фирменными цветами.
